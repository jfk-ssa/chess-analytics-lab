## Failure evidence and boundaries

Tests exercise illegal moves, malformed headers, incomplete endings, optional
missing fields, mate/clock preservation, duplicates, annotation conflicts, tampered
staging, checksum failure, source/expanded/record/game/disk limits, shared retry byte
allowance, retained acquisition jobs, read-only access and writer locking.
An injected pre-publication failure preserves the prior snapshot; retry matches a
clean run. Test fixtures and failure injection are explicitly synthetic.

Full manifests and attempts remain under ignored data/. Original bootstrap package
and environment failures are documented in DECISIONS.md. Model usage/cost is not
reported as a measured zero: no live-model experiment exists.

The archive is historical. This milestone makes no opening, clock-pressure,
contemporary-population, causal, or model-performance claim. M2 adds dbt lineage,
broader recovery and operational reporting before Dagster.
