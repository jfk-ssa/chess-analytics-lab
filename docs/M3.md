# M3 — bounded analytical corpus and metrics

M3 is accepted locally. All data and analyses are offline after the bounded
download. The [phase tracker](STATUS.md) records what is next.

## Source and reproducibility

The fixed source is the [Lichess August 2026 standard rated archive](https://database.lichess.org/).
`config/datasets.json` pins the first 40,000,000 compressed bytes and their
SHA256. Extraction retains the first 100,000 **complete** PGNs and drops any
trailing partial record. The input is explicitly partial; neither its prefix hash
nor this run verifies the publisher's full-archive checksum. Local ignored `data/`
contains the retained prefix, extracted PGNs, published snapshots and failed
attempts. [Acquisition](../reports/M3-acquisition.json),
[extraction](../reports/M3-extraction.json) and
[source manifest](../reports/M3-source-manifest.json) preserve their identities.

From the repository root, after `uv sync --locked --no-editable --extra dbt`:

```sh
.venv/bin/python -m analytics_m3 acquire
.venv/bin/python -m analytics_m3 extract
.venv/bin/python -m analytics_m3 ingest
.venv/bin/python -m analytics_m3 moves
.venv/bin/python -m analytics_m3 report
.venv/bin/python scripts/reference_m3.py > reports/M3-independent-reference.json
.venv/bin/python scripts/check_m3_reference.py
.venv/bin/python scripts/report_m3_coverage.py
.venv/bin/python scripts/build_m3_dev_cases.py
```

These commands do not call an AI provider. `acquire` uses the verified local
prefix when present; downloading the fixed range requires network access. The
caps are 500 MB each for retained compressed and expanded input and 5 GB for
generated data. A failed run remains on disk for inspection and counts against
the generated-data allowance. Rebuilding after source/contract code changes
produces a new snapshot ID; downstream references and cases must then be rebuilt.

## Observed coverage and metric boundaries

[Coverage](../reports/M3-coverage.json) records 100,000 complete PGNs, 99,467
accepted rated games and 533 unrated exclusions. The **only observed UTC date is
2026-08-01**. No estimate for the rest of August follows from this ordered
prefix. Among accepted games, recorded UTC date/time, participant ratings and
source opening tags have zero missing values; that does not establish their
accuracy or population representativeness.

Opening family is the source Opening tag before its colon. The opening metric
uses 99,117 eligible completed, non-marked-bot games. The move table selects
games by SHA256 game-ID modulo 20, independently of annotation presence: 4,924
selected games, including 10 with zero plies, and 330,956 move rows. This is a
deterministic subsample **within the prefix**, not a monthly sample.

The clock proxy uses zero-increment games and a prior same-player clock as time
before a move. It compares source centipawn evaluations in the mover's
perspective and flags deterioration of at least 200 cp. Missing evaluations and
mate scores do not become zero errors. Evaluable coverage ranges from about
5.7% to 10.6% across the four clock buckets. These are descriptive annotations,
not an official blunder label or evidence that time pressure caused mistakes.
The precise grains, filters and null rules are in the
[metric registry](METRICS.md) and versioned contracts.

## Acceptance evidence

The [independent reference](../reports/M3-independent-reference.json) scans raw
PGN headers and comments without the M3 metric implementation. The
[comparison](../reports/M3-reference-check.json) passed for the 12 leading
opening families, four opening/player cohorts, all four clock buckets, source
draw counts and selected move counts. It checks arithmetic and extraction
semantics, not external annotation accuracy. The
[12 draft development cases](../evals/cases/dev/m3_cases.json) include answerable,
ambiguous and unsupported questions; no model response or benchmark score exists.

M0–M2 were rebuilt after the shared ingestion change. The
[tiny](../reports/M3-tiny-m2-regression.json) and
[foundation](../reports/M3-foundation-m2-regression.json) mart runs each created
five models and passed 19 dbt tests. The foundation still has 121,332 accepted
games and 3,982 eligible draws. The [foundation regression report](../reports/M3-foundation-regression.json)
preserves its validated metric and current snapshot ID. Earlier immutable
snapshots and prior milestone reports remain historical evidence.
