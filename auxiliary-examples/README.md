# Auxiliary examples

These examples are separate from Chess Analytics Lab. They illustrate business
metric communication and data observability dashboard presentation; neither is
used by the chess pipeline, tests, or evaluation.

- [Executive metric definition standard](exec-metric-definition-standard.md)
- [Data observability dashboard screenshot](data-observability-dashboard.png)

The metric standard is a public adaptation of the supplied text. Its financial
figures and worked scenarios are synthetic; named people, email addresses,
customer records, internal links, and production history have been removed.
The dashboard is the supplied PNG screenshot. It shows monitor health and
anomaly counts, not financial values. These are reference examples, not Chess
Analytics Lab results. They are excluded from the Python distributions; no
separate license grant for these examples is stated here.
